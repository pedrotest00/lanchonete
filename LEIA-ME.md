# Mordi — landing page de lanches

Projeto demonstrativo de uma landing page responsiva para uma marca fictícia de lanches.

## Arquivos

- `index.html`: página principal.
- `style.css`: estilos, identidade visual e responsividade.
- `script.js`: filtros do cardápio, sacola e interações.
- `video.js`: aviso caso o arquivo de vídeo ainda não tenha sido adicionado.
- `experiencia.html`: página separada para exibir o vídeo.
- `videotop.mp4`: arquivo de vídeo que você deve adicionar à pasta do projeto.
- `GUIA-COMMIT-POWERSHELL.md`: passo a passo para enviar o projeto ao GitHub pelo PowerShell.

## Como visualizar

Abra `index.html` no navegador. Para testar a página do vídeo, adicione `videotop.mp4` à pasta e abra `experiencia.html`.

As fotografias do cardápio são carregadas do Unsplash, então precisam de conexão com a internet. Os textos e preços são demonstrativos e podem ser editados diretamente no `index.html`.

## Observação sobre a página separada

`experiencia.html` não possui link na navegação da página principal. Isso a deixa fora do caminho normal de navegação, mas não cria proteção por senha.


As imagens do site ficam armazenadas localmente em `assets/images/`, para evitar imagens quebradas por dependência de serviços externos. O botão do vídeo especial aparece no destaque final, antes do rodapé.
